## Course Overview

This folder holds all problem sets, labs and quizzes for MATH 141. It is part of the Fall 2026 submissions repo (see `../README.md`) — there is no separate repository here.

## Structure

One folder per teaching week (`week0/` … `week12/`). Each holds that
week's answer sheets alongside any Python or Desmos work for the labs.

| Week | Topic | Sheets |
|---|---|---|
| `week0/` | Review — functions, algebra, trigonometry | PS 0, Lab 0 |
| `week1/` | Limits — intuition, ε-δ, limits at infinity | PS 1, Lab 1, Quiz 01 |
| `week2/` | Continuity & the Intermediate Value Theorem | PS 2, Lab 2, Quiz 02 |
| `week3/` | The derivative — definition & differentiability | PS 3, Lab 3, Quiz 03 |
| `week4/` | Differentiation rules, chain rule, higher derivatives | PS 4, Lab 4, Quiz 04 |
| `week5/` | Implicit differentiation, logs, inverse trig, related rates | PS 5, Lab 5, Quiz 05 |
| `week6/` | Extrema, Rolle & the MVT, L'Hôpital's rule | PS 6, Lab 6, Quiz 06, **Midterm 1** |
| `week7/` | Shape of a graph, curve sketching, optimization | PS 7, Lab 7, Quiz 07 |
| `week8/` | Riemann sums & the definite integral | PS 8, Lab 8, Quiz 08 |
| `week9/` | The Fundamental Theorem of Calculus | PS 9, Lab 9, Quiz 09 |
| `week10/` | Substitution, symmetry, integration by parts | PS 10, Lab 10, Quiz 10, **Midterm 2** |
| `week11/` | Applications — area between curves, volumes | PS 11, Lab 11, Quiz 11 |
| `week12/` | Review, Taylor polynomials preview, final prep | Lab 12, Quiz 12, **Final Exam** |

40 sheets in total. Labs meet on the Friday of their own week. Quizzes cover the previous week, so `Quiz 12` sits in `week12/` and examines Week 11. Lab 0 and Lab 12 are ungraded, and PS 12 is an optional revision set, so it has no sheet.
