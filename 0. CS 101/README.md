## Course Overview

This folder holds all assignments, labs, and projects for CS 101. It is part of the Fall 2026 submissions repo (see `../README.md`) — there is no separate repository here.

## Structure

One folder per teaching week (`week0/` … `week12/`). Each holds that
week's answer sheets alongside any code written for it.

| Week | Topic | Sheets |
|---|---|---|
| `week0/` | Orientation & setup | Lab 0, Quiz 0 |
| `week1/` | Data, types, variables, expressions | PS 1, Lab 1, Quiz 1 |
| `week2/` | Control flow: conditionals & iteration | PS 2, Lab 2, Quiz 2 |
| `week3/` | Functions, scope, the call stack | PS 3, Lab 3, Quiz 3 |
| `week4/` | Recursion | PS 4, Lab 4, Quiz 4 |
| `week5/` | Searching & sorting | PS 5, Lab 5, Quiz 5 |
| `week6/` | Algorithm analysis — Big-O | PS 6, Lab 6, Quiz 6, **Midterm 1** |
| `week7/` | Data structures I — lists, stacks, queues | PS 7, Lab 7, Quiz 7, **Project 1** |
| `week8/` | Data structures II — hash tables & sets | PS 8, Lab 8, Quiz 8 |
| `week9/` | Strings & regular expressions | PS 9, Lab 9, Quiz 9 |
| `week10/` | Files, I/O, error handling | PS 10, Lab 10, Quiz 10, **Midterm 2** |
| `week11/` | Computability & undecidability | PS 11, Lab 11, Quiz 11 |
| `week12/` | Synthesis & review | **Project 2**, **Final Exam** |

40 sheets in total. A sheet's week is the week its assessment was set in, so `Quiz 11` sits
in `week11/` even though it examines Week 10 material.
