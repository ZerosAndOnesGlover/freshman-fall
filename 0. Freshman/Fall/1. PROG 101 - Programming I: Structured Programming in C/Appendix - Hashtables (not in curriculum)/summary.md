# PROG 101 · Appendix · Summary

**Topic —** Hash tables — **not part of the PROG 101 curriculum**; supplementary material completing the foundational trio with linked lists (Week 7) and binary search trees (Week 9).
**Lectures —** L01 Hash Functions and the Hashing Problem; L02 Collision Resolution — Chaining and Open Addressing; L03 Building a Complete Hash Table and Applications.
**Work —** Lab, problem set and quiz included, all optional and ungraded — none of it appears in the gradebook.
**Takeaway —** Collisions are mathematically unavoidable, so a hash table is really a hash function plus a collision strategy plus a load-factor policy; average-case O(1) is a statement about all three, not about the hashing alone.
