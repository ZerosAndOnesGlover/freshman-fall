# PROG 101 · Week 1 · Summary

**Topic —** Types, variables, and the memory model
**Lectures —** L01 Types, Variables, Memory; L02 Integer Representation; L03 Floating Point and Conversions.
**Work —** PS 1, Lab 1 (memory, bits, loops). No quiz.
