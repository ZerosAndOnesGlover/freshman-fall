**1. C** — time to fall depends only on h = ½gt²; horizontal speed has no effect on vertical fall time.

**5.** Horizontal: x = v₀t → t = 36/12 = 3.0 s. Vertical: H = ½gt² = ½(9.81)(9.0) = **44.1 m**

**6. C** — speed (magnitude of velocity) is constant. Velocity direction and acceleration direction both change continuously.

**7.** a_c = ω²r = (36)(0.50) = **18 m/s²**

**8. B** — a_c = v²/r; doubling v quadruples v², so a_c quadruples.

**9.** a_c = v²/r = 625/200 = **3.125 m/s²**; |a| = √(3.125² + 1.5²) = √(9.766 + 2.25) = √12.016 = **3.47 m/s²**
