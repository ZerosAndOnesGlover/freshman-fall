## The Circularity Problem (Enrichment)

Newton's second law seems to define force as F = ma — but we also use force meters (springs) calibrated independently to measure forces. There is a subtle logical circularity: we define force by its effect (acceleration of mass), but we also define mass by how it responds to force. The resolution is operational: we define a unit mass, use it to define unit force (1 N = force that gives 1 kg an acceleration of 1 m/s²), then measure other masses by comparing their responses to the same force. The laws work not because they are logically airtight, but because they describe nature with extraordinary precision.

## Common Pitfalls This Week

1. **Putting reaction forces on the same FBD.** Newton's Third Law pairs act on different objects. Each FBD has only the forces on that one object.

2. **Setting N = mg by default.** Normal force equals mg only on a horizontal surface with no vertical acceleration and no other vertical forces. Always determine N from ΣFᵧ = may.

3. **Confusing static and kinetic friction.** Static friction is variable (0 to μ_s N); kinetic friction is fixed at μ_k N. Ask first: is the object sliding or not?

4. **Sign errors in connected-body problems.** Carefully define which direction is positive for each object. The string forces one acceleration magnitude to be shared — choose sign conventions that make this explicit.

5. **Forgetting that friction opposes relative motion — not absolute motion.** On an incline, if a block is being pushed UP the slope, kinetic friction acts DOWN the slope (opposing the relative motion). If sliding DOWN, friction acts UP. Always identify the direction of motion first.
