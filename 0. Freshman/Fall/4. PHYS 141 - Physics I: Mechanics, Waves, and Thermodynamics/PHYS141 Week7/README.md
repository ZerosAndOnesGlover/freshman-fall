## Learning Objectives

By the end of Week 7, you will be able to:

1. Define angular momentum for a point particle (L⃗ = r⃗ × p⃗) and for a rigid body (L = Iω)
2. Derive τ⃗ = dL⃗/dt from Newton's second law, paralleling the linear F⃗ = dp⃗/dt relationship
3. State and apply conservation of angular momentum for isolated rotational systems
4. Explain the physics of spinning skaters, divers, and gyroscopes using angular momentum conservation
5. Solve collision problems involving rotating bodies (e.g., a falling object landing on a rotating disk)
6. State the two conditions for static equilibrium (ΣF⃗=0 and Στ⃗=0) and explain why both are independently necessary
7. Define center of gravity and distinguish it from center of mass in a non-uniform gravitational field
8. Solve beam, ladder, and hanging-sign equilibrium problems using torque balance
