## Problem 1: Algebraic Limits (18 points)

Evaluate each limit, or state that it does not exist (DNE). Justify each answer. *(6 pts each)*

**(a)** $\displaystyle\lim_{x \to -2} \frac{x^2 + 5x + 6}{x^2 - x - 6}$

**(b)** $\displaystyle\lim_{x \to 0} \frac{\sqrt{4 + x} - 2}{x}$ *(Hint: rationalize the numerator.)*

**(c)** $\displaystyle\lim_{x \to 1^-} \frac{|x - 1|}{x - 1}$ and $\displaystyle\lim_{x \to 1^+} \frac{|x - 1|}{x - 1}$. Does the two-sided limit exist?

## Problem 5: Making a Limit Exist (12 points)

Find every value of the constant $a$ for which $\displaystyle\lim_{x \to 2} g(x)$ exists, where

$$g(x) = \begin{cases} ax + 3 & x < 2 \\ x^2 - a & x \geq 2 \end{cases}$$

Compute both one-sided limits in terms of $a$, and state the value of the limit for your $a$.

## Problem 6: An ε-δ Proof, Linear (12 points)

Using the formal $\varepsilon$-$\delta$ definition, prove $\displaystyle\lim_{x \to 5} (3x - 7) = 8$.

Your proof must: (i) begin with "Given $\varepsilon > 0$," (ii) state your choice of $\delta$, and (iii) verify the implication.

## Problem 7: An ε-δ Proof, Quadratic (14 points)

Using the formal $\varepsilon$-$\delta$ definition, prove $\displaystyle\lim_{x \to 3} x^2 = 9$.

*(Hint: follow Lecture 02 Example 2. Restrict $\delta \leq 1$ first to bound the factor $|x + 3|$, then choose $\delta = \min(1, \varepsilon/7)$.)*

## Problem 8: What a Limit Ignores (10 points)

A student writes: *"Since $f(2) = 5$, we know $\lim_{x \to 2} f(x) = 5$."*

Is this correct? Explain what the limit does and does not depend on, and give a piecewise function with
$f(2) = 5$ whose limit at $2$ is not $5$.
