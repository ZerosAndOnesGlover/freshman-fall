**Week 2, Monday, first 15 minutes of lecture · 20 points**
**Covers Week 1** — binary trees, traversals, and binary search trees. **Not** this week's material.

Closed book. No calculator required — every number here is exact.
Height counts **edges**; the empty tree has height $-1$.

---

**Q1.** *(3)* A binary tree has 7 nodes. Give the smallest and largest possible height.

---

**Q2.** *(4)* For the tree

```
        50
       /  \
     30    70
    /  \     \
  20    40    80
```

write out the **preorder**, **inorder**, and **postorder** sequences.

---

**Q3.** *(3)* Insert $5, 3, 8, 1, 4, 7, 9$ into an empty BST in that order. Draw the tree and give its
height.

---

**Q4.** *(4)* Delete the key $3$ from your tree in Q3. Which of the three deletion cases is it, and
what is the resulting tree?

---

**Q5.** *(3)* Is this a valid BST? If not, name **one** node that violates the invariant and say why.

```
        10
       /  \
      5    15
          /  \
         6    20
```

---

**Q6.** *(3)* A BST built by inserting $n$ keys in sorted order has height $n-1$. State in one
sentence why this is a more serious problem than a merely unlucky worst case.
