# ECE 110 · Week 0 · Summary

**Topic —** Number systems: binary, octal, hex, conversions, two's complement and BCD — how a machine holds a number.
**Lectures —** L01 Number Systems and Conversions; L02 Signed Numbers and BCD.
**Work —** PS 0 (100), Lab 0 (100, the conversion bench). **No quiz** — quizzes begin Week 2 and are ungraded all term.
**Takeaway —** Carry and overflow are independent flags: all four (C, V) combinations occur, and V = C_in ⊕ C_out was verified against true arithmetic on all 65,536 signed 8-bit pairs. BCD is not "more accurate" — it buys exactness for finite decimal fractions with ~20% more bits.
