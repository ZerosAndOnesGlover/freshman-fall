## Part D — Concept (10 pts each)

**D1.** *(The theorem.)* Lecture 3 claimed that **every rational function has an elementary antiderivative**, and sketched why.

Reconstruct that argument in your own words, as four steps. For each step, say what would go wrong if it failed. Then state precisely which kinds of function can appear in the answer, and identify which feature of the denominator produces each kind.

**D2.** *(A student's error.)* A student is asked for $\displaystyle\int\frac{x^3+4}{x^2+4}\,dx$ and writes:

> "The denominator $x^2+4$ is an irreducible quadratic, so the decomposition is
> $$\frac{x^3+4}{x^2+4} = \frac{Ax+B}{x^2+4}$$
> Multiplying up gives $x^3+4 = Ax+B$, and comparing coefficients gives $A=0$, $B=4$, and $0=1$ for
> the $x^3$ term — which is impossible, so the integral cannot be done."

- (a) Identify the student's error precisely. Which step of the algorithm did they omit?
- (b) Explain why the contradiction $0=1$ appeared — what is it actually telling them?
- (c) Do the problem correctly. *(This is C5; you may refer to your answer.)*
- (d) The student concluded "the integral cannot be done." Given the theorem in D1, explain in one sentence why that conclusion was never possible for this integrand.
