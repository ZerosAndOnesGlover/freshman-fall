## Questions

**Q1.** The region under $y=x^2$ on $[0,1]$ is rotated about the **$x$-axis**. Find the volume.

**Q2.** The region under $y=x^3$ on $[0,1]$ is rotated about the **$y$-axis**. Find the volume, using shells.

**Q3.** The region between $y=1$ and $y=x^2$ on $[0,1]$ is rotated about the **$x$-axis**. Find the volume.

**Q4.** Find the arc length of $y=\tfrac23(x+1)^{3/2}$ on $[0,3]$.

**Q5.** Find the area of the surface generated by rotating $y=\sqrt x$ on $[0,3]$ about the **$x$-axis**.

# ANSWER KEY

---

**Q1. (4)** Discs of radius $x^2$:

$$V = \pi\int_0^1 x^4\,dx = \boxed{\frac\pi5}$$

*Marking: 1 setup, 3 evaluation. Verified symbolically.*

**Q2. (4)** Shells of radius $x$, height $x^3$:

$$V = 2\pi\int_0^1 x\cdot x^3\,dx = 2\pi\cdot\frac15 = \boxed{\frac{2\pi}{5}}$$

*Marking: 2 for the correct (radius)(height), 2 evaluation. Verified symbolically.*

**Q3. (4)** Washer: the region lies between the curve and the line $y=1$, so **outer radius 1, inner radius $x^2$**:

$$V = \pi\int_0^1\Big[1^2-(x^2)^2\Big]dx = \pi\left(1-\frac15\right) = \boxed{\frac{4\pi}{5}}$$

*Marking: **2 of the 4 for the correct outer/inner assignment.** Writing $\pi\int(1-x^2)^2dx$ is the standard error and scores 1. Verified symbolically.*

*Note $Q_1+Q_3 = \frac\pi5+\frac{4\pi}{5} = \pi$ — the volume of the full cylinder of radius 1 and height 1, as it must be. **A free check worth pointing out.***

**Q4. (4)** $y' = (x+1)^{1/2}$, so $1+(y')^2 = 1+(x+1) = x+2$:

$$L = \int_0^3\sqrt{x+2}\,dx = \left[\frac23(x+2)^{3/2}\right]_0^3 = \frac23\left(5^{3/2}-2^{3/2}\right) = \boxed{\frac{10\sqrt5-4\sqrt2}{3}}$$

$\approx 5.567$

*Marking: 2 for simplifying $1+(y')^2$ to $x+2$, 2 for evaluation. **The curve is engineered so the root becomes linear** — as in Week 4, C1. Verified symbolically.*

**Q5. (4)** $y' = \tfrac{1}{2\sqrt x}$, so

$$S = 2\pi\int_0^3\sqrt x\sqrt{1+\frac{1}{4x}}\,dx = 2\pi\int_0^3\sqrt{x+\frac14}\,dx = \boxed{\frac{\pi\big(13\sqrt{13}-1\big)}{6}}$$

$\approx 24.12$

*Marking: 1 for using $ds$ not $dx$, **2 for combining the radicals**, 1 evaluation. Verified symbolically.*
