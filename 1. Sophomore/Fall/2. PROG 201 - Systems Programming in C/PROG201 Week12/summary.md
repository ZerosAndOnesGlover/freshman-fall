# PROG 201 · Week 12 · Summary

**Topic —** Synthesis: turning a working concurrent server into a production daemon that runs unattended — signals and graceful shutdown, capacity, leak-freedom, a hardened and fuzzed parser, privilege handling and resource limits — with every property measured.
**Lectures —** L37 The Production Daemon (Signals and Graceful Shutdown); L38 Concurrency and Capacity; L39 Running Unattended, and the Synthesis.
**Work —** **Project 2 (a production HTTP daemon, 12.5%) due Friday 17:00**, demo at Lab 12 (Monday of the completion period). **No quiz** — Weeks 11–12 are examined on the comprehensive final. Lab 11 is sat Monday of this week; Lab 12 is demo day + peer code review. `ab` is not installed, so the course ships its own harness (`bench`, `rudeclient`); every figure was produced on the reference machine (Intel i5-8250U, 8 CPUs, Linux 7.0.0-30) by a named program.
**Takeaway —** The difference between working code and code that runs unattended is the measurement you take after you think you are done. A **signal** is an asynchronous interrupt, so a handler may call only **async-signal-safe** functions (`write` yes; `printf`/`malloc` no) and must expect `EINTR` on blocking calls; the **self-pipe trick** turns a signal into a readable fd so the *response* runs in the main loop. On **`SIGTERM`** the daemon **drains** — stop accepting, finish in-flight requests, join workers — measured **exit 0** with responses delivered, versus a handler that `exit()`s mid-request and truncates them. The week's central pair is **SIGPIPE**: the server checks every `write` return value (careful I/O — the mechanism is present), yet a client that hangs up mid-response **kills it**, because the kernel raises `SIGPIPE` (default disposition: terminate) *before* `write` returns `-1`/`EPIPE` — measured **exit 141** (128+13). One line, `signal(SIGPIPE, SIG_IGN)`, makes the identical scenario return `EPIPE` and the server **survives, exit 0**. That is the **sixth** "a mechanism present is not a mechanism working" (after W3 `PRIO_INHERIT`, W8 lazy binding, W10 ASLR-without-PIE and inert CET, W11 stripped userns). Concurrency uses a **thread pool + bounded queue + condition variables**: the bound gives **backpressure** (accept blocks instead of the heap growing — the Week 11 fork bomb moved to userspace). **Capacity is two regimes, measured on one server:** a trivial `GET /` handler is **flat at ~36k req/s across 1–16 workers** (accept-bound; 16 workers is *slower* than 4), while a blocking `GET /slow` handler scales **linearly, 5×workers** (5/10/20/40 req/s for 1/2/4/8) — so "add threads" is right only when requests block, and only a load test says which regime you are in (Week 9's lesson at the server). The **p99 (11 ms)** is the SLA number, not the mean (2.3 ms). **Running unattended means not growing:** file descriptors measured at **delta 0** across 10 000 requests and **RSS flat at 1728 kB across 50 000** — leak-freedom is a watched line, not an assertion. A privileged port needs root (**`bind :80` → EACCES** unprivileged), so a daemon **starts privileged and drops** — `setgroups(0,NULL)` then `setgid` then `setuid`, in that order — and the **seventh** "present but not working" is `setuid` **without** `setgroups`: the drop looks done (`getuid()` shows the new uid) but the process **keeps root's supplementary groups**, visible only in the `Groups:` line of `/proc/self/status`. Supervision is inverted (foreground, log to stderr, `systemd` owns the lifecycle): `Restart=on-failure`, `User=`, `MemoryMax`/`TasksMax` (the Week 11 cgroup caps), and `AmbientCapabilities=CAP_NET_BIND_SERVICE` (bind :80 with one capability, not full root). The parser is the attack surface, hardened by Week 10 as routine: bounded reads, the guard build (`-Werror -fstack-protector-strong -D_FORTIFY_SOURCE=2`), and `libFuzzer`+ASan on the parse function. The synthesis: a fuzzed parser + dropped privilege + a cgroup budget + a supervisor + SIGPIPE-ignored/SIGTERM-drain is defence in depth, every layer of the course catching the failure of the one before — and running through all of it, the law the course returns to seven times: *distrust your own success until you have measured it.*
