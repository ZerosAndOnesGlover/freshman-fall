**Takeaway —** Week 6 measured a trivial program at **532 µs static and 679 µs dynamic** and did not say where the difference went: into `/lib64/ld-linux-x86-64.so.2`, which `execve` runs instead of your binary. Static costs **785,232 bytes against 16,056** for the same three-line program — 49× — and buys one file with no environment to get wrong; dynamic buys one shared copy of libc in physical memory, one-place security updates, plugins and interposition. `ldd` prints three lines and one of them, **`linux-vdso.so.1`, is not a file** — the kernel maps it in, and it is why `clock_gettime` needs no system call. A cross-library call goes through **a read-only PLT stub and a writable GOT slot**, so the code stays shareable; with lazy binding the GOT slot **initially holds the address of its own PLT stub**, which you can read out of `.got.plt` as `0x1030` and `0x1040`, so the first call falls into the resolver and the second goes straight through. **Except that lazy binding is off by default here**: Ubuntu builds `-z relro -z now`, everything binds before `main`, and the GOT is then made read-only — because a writable GOT is what a GOT-overwrite attack needs. `-fPIC` costs **two loads instead of one** for a global and is mandatory: a non-PIC object cannot be linked into a shared library at all. Then interposition — **the first definition found wins**, so twelve lines and `LD_PRELOAD` replace `time()` in any program — and its three measured limits: `-O2` **deleted all 1,010 malloc/free pairs** so there was nothing to intercept, interposing `time` does nothing to `date` because `date` calls `clock_gettime` through the vDSO, and `ld.so` **runs no destructors at all for `ls` and `grep`**, so a destructor-based report silently prints nothing. `dlopen` with `RTLD_NOW|RTLD_LOCAL`, check `dlerror` and not the return value, and give a plugin **one exported symbol with an ABI number**. One `libc.so.6` holds **`memcpy@GLIBC_2.2.5` and `memcpy@@GLIBC_2.14`** among 41 version definitions, which is why old binaries run on new systems and not the reverse.
