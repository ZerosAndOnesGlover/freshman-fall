**Takeaway —** The same out-of-bounds read gets four different answers: C returns `29291` with no diagnostic and keeps going, Java and Python raise, and **JavaScript returns `undefined` with no error at all** — so "safe" is at least two properties, and JS is memory-safe while being diagnostically unsafe. On identical naive Fibonacci, C/Java/JS/Python run 0.004/0.025/0.037/0.353 s at fib(30) but 0.028/0.037/0.075/0.551 s at fib(32) — **Java goes from 6.3× C to 1.3× because the JIT warmed up**, which means almost every "N times slower" claim is a warm-up artefact. Source length ran inverse to speed (18/10/6/5 lines), though the measurement is confounded and Python is short *and* slow for one shared reason rather than by causation. Each language made one central decision and paid for it everywhere else, and this course measured most of those costs; Rust did not abolish the safety/performance trade but moved it to compile time and onto the programmer, with one aliasing rule killing use-after-free and data races together. Honest limit recorded: our compiler emits a valid wasm32 object but `wasm-ld` is absent, so it cannot be linked and run here — a missing linker, not a missing compiler.
