## Course Overview

This folder holds all problem sets, labs and quizzes for MATH 151. It is part of the Fall 2026 submissions repo (see `../README.md`) — there is no separate repository here.

## Structure

One folder per teaching week (`week0/` … `week12/`). Each holds that
week's answer sheets alongside any Python written in the labs.

| Week | Topic | Sheets |
|---|---|---|
| `week0/` | Propositional logic — connectives, truth tables, tautologies | PS 0, Lab 0 |
| `week1/` | Predicate logic, quantifiers, logical equivalences | PS 1, Lab 1, Quiz 1 |
| `week2/` | Proof techniques — direct, contrapositive, contradiction | PS 2, Lab 2, Quiz 2 |
| `week3/` | Mathematical induction — weak & strong | PS 3, Lab 3, Quiz 3 |
| `week4/` | Sets — operations, power sets, Cartesian products | PS 4, Lab 4, Quiz 4 |
| `week5/` | Functions — injective, surjective, bijective; cardinality | PS 5, Lab 5, Quiz 5 |
| `week6/` | Relations — equivalence classes, partial orders | PS 6, Lab 6, Quiz 6 |
| `week7/` | Counting — permutations, combinations, binomial theorem | PS 7, Lab 7, Quiz 7 |
| `week8/` | Advanced counting — pigeonhole, inclusion–exclusion | PS 8, Lab 8, Quiz 8 |
| `week9/` | Recurrence relations & generating functions | PS 9, Lab 9, Quiz 9 |
| `week10/` | Graphs — terminology, representations, connectivity | PS 10, Lab 10, Quiz 10 |
| `week11/` | Trees, spanning trees, BFS & DFS | PS 11, Lab 11, Quiz 11 |
| `week12/` | Number theory — divisibility, modular arithmetic, RSA | PS 12, Lab 12, Quiz 12, **Final Exam** |

39 sheets in total. Lab N meets on the Wednesday of Week N+1, after all three of that week's lectures. Quizzes cover the previous week, so `Quiz 12` sits in `week12/` and examines Week 11.
